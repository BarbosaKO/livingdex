🚀 Como começar

  • Configurar: Execute python seed.py para carregar os metadados de espécies e jogos iniciais.
  • Iniciar: Rode python run.py ou flask run para iniciar o servidor.
  • Adicionar: Vá em "Coleção" e clique em "+ Adicionar Pokémon" para cadastrar manualmente.
  • Organizar: Use o sistema de Boxes para organizar visualmente seus Pokémon.
  • Importar: Faça upload de arquivos .sav na seção "Importar" para extrair Pokémon.
